# Changelog

All notable changes to this project will be documented here.

## 0.1.0 - 2026-09-03

- Add deterministic k-mer fingerprinting and MinHash signatures.
- Add LSH band indexing with exact fingerprint-Jaccard reranking.
- Add strict FASTA and timestamped JSONL ingestion.
- Add bounded older-to-newer similarity graph construction.
- Add portable JSON indexes, CLI workflows, tests, builds, and CI.
